# Сайт «Основания»

https://osnovanie.z1nex.ru — витрина агента [osnovanie](https://github.com/z1nex-1/osnovanie): главная, реплей живого прогона по брифу МегаФона, «Как устроено», пульт проекта и страница проверок.

Ни одно число на страницах не вписано руками. `build.py` берёт их из `docs/facts.json` и `docs/CRITERIA.md` агента и из `data/`, поэтому после нового прогона сайт пересобирается одной командой. Реплей читает журналы прогона: `data/live/replay.json` — прогон по брифу, `?run=/data/ref/replay.json` — эталон.

## Сборка

Нужны Python 3.11+ и Node 20+. Папка агента должна лежать рядом: `../osnovanie`.

```bash
python3 -I build.py
cd web && npm ci && npm run build
```

Готовая статика появится в `web/dist`. Локальный просмотр — `npm run preview`.

## Что где

| Папка | Содержимое |
|---|---|
| `src/`, `site/` | главная: шаблон и собранная страница |
| `web/` | реплей, «Как устроено», пульт, проверки (Vite) |
| `data/` | факты и журналы прогонов для реплея |
| `design/` | дизайн-исследование, знак, сценарий ролика |
| `DESIGN.md` | токены, шрифты, запреты |
| `THIRD_PARTY.md` | шрифты и библиотеки с лицензиями |

Работа для конкурса MGIMO AI Challenge 2026, номинация «ИИ-проект». Неофициальный материал, не позиция ПАО «МегаФон».
