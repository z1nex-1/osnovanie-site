    Как устроен реплей

    Тот же формат,
    что у живого прогона

    Команда osnovanie replay build читает журналы Claude Code и состояние проекта и собирает файл схемы osnovanie-replay/1: реплики, вызовы инструментов, утверждения, точки человека и деньги. Рассуждения модели, системные вставки и тексты из карантина в файл не попадают, похожие на секреты фрагменты вычищаются — иначе файл не пишется.

    На этой странице сейчас — эталонный проект. Его собрал детерминированный движок «Основания» из 27 открытых цитат, чтобы показать механику, а ответы в точках дала демо-команда. Шкала — порядок событий, а не секунды. Когда появится живой прогон, он встанет сюда тем же файлом, и вверху будет написано, чей он.
