# Геном: Основание

Направление выбрано z1nex: киберпанк/хайтек, зелёные акценты под кейс МегаФона, рисунки в Illustrator не в нашем обычном стиле (см. `scout.md`, поправка 17.11).

Главное изображение, откуда: **настоящий текст источника** — сырой текст страницы moscow.megafon.ru/corporate/services/mega_ai, снятый 17.11.2026 в 23:15 (строки 205–282 извлечённого текста, sha256 текста `cd4e7ef2…64be43`). Ровно то, что читает агент: без вёрстки МегаФона, без логотипа. Документ лежит на тёмном «столе сканера», вне луча он виден растром, в луче — резким. Вторая картинка — граф утверждений из `graph.json`.
Обработка изображений: единый **растр-дизеринг по Байеру** (точка 3 px) для всего, что «ещё не прочитано»: документ вне луча, рисунки в покое, фон-шейдер. Прочитанное и проверенное — резкая векторная линия. Правило читается без подписи: растр = сырой материал, линия = утверждение с основанием.
Палитра, источник: фон #07100C (PLAN §2, выбор z1nex: тёмный с зелёной глубиной); акцент #0CDC78 — `brandGreen80` из CSS moscow.megafon.ru (10,6:1 на фоне); #00B956 — основной зелёный МегаФона, только крупные плашки с тёмным текстом (6,9:1), белый на нём запрещён; гипотезы — янтарь #FFA717 (тот же CSS, 9,9:1); возражения — #FF5A64, осветлённый #F62434 из CSS до 6,3:1; бумага документа #DDE6E0 — холодная, тон 157°, с чернилами #0A140F (14,7:1) и проверенной ссылкой #00753A (4,6:1). Зелёный — не больше 8 % площади и только там, где есть основание.
Сетка, от чего: колонки — это **поля утверждения**: тип · цитата · источник · дата · отпечаток. 12 колонок base.css группируются 2/5/2/1/2 по этим полям везде, где стоит утверждение (сканер, реестр, таблица чата). Вертикальный шаг — строка документа-источника (28 px): сканер идёт ровно по строкам.
Шрифты, причина: заголовки, логотип, цифры — **своя гарнитура** (узкий технический гротеск, срезы под прямым углом и под 45°, моно-ритм: штамбы стоят через равные просветы, как символы на табло прибора), нужна, потому что огромные цифры стоимости и счётчики — герои секций 2 и 7, а кириллица в техно-гротесках с OFL слабая. Текст — IBM Plex Sans (OFL, причина: инженерная гарнитура с ровной кириллицей и табличными цифрами, читается в 17 px на тёмном). Данные — IBM Plex Mono (OFL), только там, где данные: id, хеши, даты, команды.
Логотип и подписные буквы: знак кодом в `saiti/kit/mark` — тема «основание под выводом»: опора, на которой стоит вывод, и отпечаток источника. Слово «Основание» контуром из своей гарнитуры, сдача через Illustrator.
Форма контейнера: **карточка утверждения со срезанным углом 45°** (срез — «вынуто из документа»: угол, которым карточка отделилась от строки). Срез один на карточку и всегда с той стороны, откуда пришла цитата. Радиус 0 везде, кроме кнопок-переключателей.
Иконки: те же срезы 45° и штрих 1,5 px, что в гарнитуре; рисуются в Illustrator одной пачкой с рисунками.
Кривая движения и жест: одна кривая `cubic-bezier(.2,.0,.0,1)` — «прибор доводит до упора»; один жест — **сканирование**: линия проходит, растр за ней становится линией. Сканер на первом экране, рост графа, волна пересмотра (та же линия, но кругами по графу, красная) — один жест в трёх масштабах.
Данные как графика: граф утверждений (сплошное — факт, пунктир — гипотеза, растр — не прочитано); диапазон калькулятора; стоимость прогона огромной цифрой; три расхождения в источниках МегаФона.
Детали (404, печать, OG, микротекст): 404 — «Такого утверждения нет в реестре», под ним растровый документ без луча; печать — только записка и реестр цитат на белом; OG — кадр сканера на реальной строке «299 ₽»; микротекст «не измерено» серым для заглушек.

## Тест костюма
Есть ли метафора: «стол сканера» и «прибор».
Убрать её — что сломается: сканер — не костюм: агент действительно читает текст источника и вынимает утверждение с отпечатком; без сцены пропадает доказательство «числа не выдуманы», ради которого сайт есть. Костюмом были бы HUD-рамки, угловые скобки, тик-шкалы и мигающие точки без данных — они запрещены (правило 3). Пульт оставляем только как функцию: всё, что выглядит прибором, показывает настоящее значение из `facts.json`.

## Правила проекта
1. Каждое число на странице — привязка к полю `facts.json` и открывается до цитаты. Заглушки серые с подписью «не измерено», никогда не придуманы.
2. Зелёный значит «есть основание» и только это; ≤ 8 % площади. Янтарь — гипотеза, красный — возражение. Никакого неонового свечения: свет — это луч сканера, а не glow у текста.
3. Никаких меток, рамок и координат без данных. Моно-подпись разрешена, только если это id, дата, хеш, команда или строка источника.
4. Растр — непрочитанное, линия — проверенное. Не смешивать.
5. Один жест движения: сканирование. Всё остальное статично; reduced-motion показывает итоговое состояние.
6. Без логотипа, слогана, вёрстки и фото МегаФона; источник показан как сырой текст.
7. Своя гарнитура только для заголовков, цифр и логотипа; читаемый текст — Plex Sans от 17 px.
